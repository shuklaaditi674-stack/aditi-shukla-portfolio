Case Study · Civic Tech / Full-Stack

Nivaran

An AI-powered civic issue reporting platform that enables citizens to report local problems such as potholes, garbage, water leakage, and damaged streetlights — simplifying complaint management while improving transparency between citizens and authorities.

My Role

Full-Stack Developer — designed the complete platform, developed the frontend and backend, and integrated complaint tracking features.

Challenges

Creating an intuitive reporting system while ensuring efficient issue categorization, location tracking, and status updates.

Architecture
  • User complaint submission with image & location support
  • Complaint categorization and status tracking
  • Admin dashboard for issue management
  • REST API-based communication between frontend and backend
Solution

Built a centralized platform that makes reporting civic issues simple while allowing authorities to monitor and resolve complaints efficiently.

Impact

Promotes faster issue reporting, transparent complaint tracking, and stronger citizen participation in local governance.

Future Scope

Integrate AI-based image recognition, automated complaint prioritization, multilingual support, and predictive analytics for smart city management.

Quiz Game · Java AWT / Swing

Bomb Quiz

A Java Swing/AWT desktop quiz game where players answer questions before the countdown timer expires. Built as one of my earliest projects to strengthen my understanding of Java programming, GUI development, and event-driven applications.

My Role

Sole Developer — designed the complete game logic, developed the GUI, implemented timer mechanics, and managed score calculation.

Challenges

Synchronizing the countdown timer with user interactions while maintaining smooth gameplay and responsive UI.

Architecture
  • Java Swing/AWT graphical interface
  • Timer-based game engine
  • Question & score management system
  • Event-driven architecture using Java listeners
Solution

Developed an engaging desktop quiz application that combines time-based challenges with interactive gameplay and score tracking.

Impact

Strengthened my foundation in Java, object-oriented programming, event handling, and desktop application development.

Future Scope

Add multiplayer mode, online leaderboards, randomized question banks, difficulty levels, and database integration for persistent scores.
